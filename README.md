# 3-Tier DevOps Project

A production-oriented 3-tier web application designed to demonstrate
modern DevOps and AWS practices from application development to
cloud deployment and monitoring.

## Architecture

Frontend → Flask API → PostgreSQL

## Technology Stack

### Application
- Python
- Flask
- PostgreSQL

### DevOps
- Git
- GitHub
- Docker
- Docker Compose
- GitHub Actions
- Trivy

### AWS
- VPC
- IAM
- ECR
- EKS
- Application Load Balancer

### Infrastructure
- Terraform

### Monitoring
- Prometheus
- Grafana
